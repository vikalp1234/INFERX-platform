# v0.1.0 verification evidence

Purpose: show that the documented environment loads the pinned model, tokenizes and generates, and that failures do not crash the process. **No performance numbers are claimed**; the only timing in this file is the wall-clock duration of the test run, which includes the first-time model download.

## Real-model contract tests

Command: `cd backend && uv sync --extra ml && uv run pytest -m model -v`

Result: **7 passed, 59 deselected** (the run took 132 s wall clock, including the first model download).

Passing tests: not loaded initially; operations before load raise `ModelNotLoadedError`; load then tokenize; unicode prompt tokenizes; generation stays within `max_new_tokens` and `prompt_tokens` matches tokenization; operations after unload raise and unload is idempotent; a failed load (nonexistent model) stays unloaded and a retry succeeds.

## CLI run

Command: `uv run python -m app.bootstrap.cli "The capital of France is" --max-new-tokens 16`

Result: exit code 0; output `prompt_tokens: 5`, then generated text beginning "Paris." Logs (stderr, JSON) recorded `prompt_tokens` 5 and `output_tokens` 16 and contained no prompt or generated text.

## Failure behavior

- Invalid (whitespace-only) prompt: exit code 1, message `error: prompt must not be empty`, no traceback (automated test `test_cli_*`).
- `ml` extra not installed: exit code 1 with `uv sync --extra ml` hint, no crash (also observed manually).
- `/health` stays 200 after a failed model load (automated test).

## CI-level checks (no model, no PyTorch)

`uv run pytest` 59 passed, 7 deselected; `ruff check`, `ruff format --check` clean; `lint-imports` 2 contracts kept, and each contract was shown to fail on a deliberate violation.

## Limitations

- Single machine, single run; not a benchmark.
- Raw prompts, no chat template; greedy decoding only.
- No timing capture, sampling controls, queue, or HTTP generate endpoints (later releases).
- Third-party libraries (for example the HTTP client used by Hugging Face) emit INFO logs to the same JSON stream, including request URLs. These contain no prompt data.
