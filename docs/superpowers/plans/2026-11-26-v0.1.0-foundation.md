# INFERX v0.1.0 — Foundation Prototype Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A documented, reproducible environment that loads one small pinned model, tokenizes a prompt and generates text through a Clean-Architecture backend with a `/health` endpoint, where failures never crash the process.

**Architecture:** Domain (value objects, errors) ← Application (use cases + `ModelExecutionPort`) ← Adapters/Infrastructure (`TransformersInferenceAdapter`, settings, JSON logging, FastAPI `/health`) ← Bootstrap (composition root, CLI). PyTorch/Transformers live in an optional `ml` extra, so CI never downloads them; a fake port drives all CI tests, and a shared contract suite runs against the real adapter locally.

**Tech Stack:** Python 3.12, uv, FastAPI, uvicorn, pydantic-settings, PyTorch + Transformers (optional extra), pytest, httpx, ruff, import-linter.

**Spec:** `docs/MASTER_IMPLEMENTATION_GUIDE.md` §6, §7, §13, §18 (v0.1.0) and `CLAUDE.md` §10 (Clean Architecture), §12, §13.

## Global Constraints

- Python **3.12**, uv, lockfile `backend/uv.lock` committed.
- Model: `HuggingFaceTB/SmolLM2-360M-Instruct`, license **Apache-2.0** (HF API, checked 2026-11-26), **pinned revision `a10cc1512eabd3dde888204e902eca88bddb4951`** (40-hex commit; model last modified 2025-09-22). Re-verify the model card before release.
- `trust_remote_code=False`, always; revision must be a 40-char lowercase hex SHA.
- Dependency rule: `domain` ← `application` ← `adapters | infrastructure` ← `bootstrap`. `domain` and `application` import no framework (fastapi, pydantic, pydantic_settings, starlette, torch, transformers, sqlalchemy, uvicorn). Enforced by import-linter in CI.
- Never log prompts or generated text. Never commit weights, `.env`, caches.
- **Out of scope (later releases):** timings/TTFT/TPOT and sampling controls (v0.2.0), generate/tokenize/stream HTTP endpoints, request IDs, queue (v0.3.0), lifecycle state machine, load timeouts, unload-while-busy protection (v1.1.x), SQLite, frontend, `/ready`. Do not pull these forward.
- Each PR must pass required checks `secret-scan` and `backend`. Before every commit: `git status`, `git diff --cached`, `gitleaks protect --staged --redact`; stage by name.
- Commit trailer: `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>`. Pushing, PR merges, tagging and the model download need the maintainer's OK.

## Review Focus

- Empty, whitespace-only or oversized prompt → `InvalidPromptError`, and the model port is never called (Task 2).
- Placeholder or unpinned revision (`main`, `REPLACE_WITH_PINNED_REVISION`, short SHA) → `InvalidModelSpecError`, never a silent load of `main` (Task 1, Task 3).
- Prompt text never appears in logs, including on error paths (Task 2).
- `ml` extra not installed → `ModelLoadError` with an install hint, not `ImportError`; `/health` stays 200 (Tasks 4, 5).
- A failed load leaves `is_loaded() == False` and a later load can succeed (Tasks 2, 4). Also unicode/emoji prompts tokenize without error (Task 4 contract test).

### Task 2: Application layer (port + use cases)

**Files:**
- Create: `backend/app/application/ports/outbound/model_execution.py`, `backend/app/application/dto/limits.py`, `backend/app/application/use_cases/{load_model,tokenize_prompt,generate_text}.py` (+ `__init__.py`s)

**Consumes:** Task 1 types.

**Produces:**
- `ModelExecutionPort(Protocol)`: `load(spec: ModelSpec) -> None`, `unload() -> None`, `is_loaded() -> bool`, `tokenize(text: str) -> TokenizationResult`, `generate(prompt: str, config: GenerationConfig) -> GenerationResult`. Contract: load failure → `ModelLoadError` and stays unloaded; any operation before load → `ModelNotLoadedError`; runtime failure → `InferenceFailedError`; `unload` idempotent.
- `InputLimits(max_prompt_chars: int, max_new_tokens: int)` frozen dataclass.
- `LoadModel(execution)`, `.execute(spec: ModelSpec) -> None`; `TokenizePrompt(execution, limits)`, `.execute(prompt: str) -> TokenizationResult`; `GenerateText(execution, limits)`, `.execute(prompt: str, config: GenerationConfig) -> GenerationResult`. Prompt invalid if empty/whitespace-only or longer than `max_prompt_chars` → `InvalidPromptError`; `config.max_new_tokens > limits.max_new_tokens` → `InvalidGenerationConfigError`. Validation happens **before** any port call.
- `FakeModelExecution(fail_load: bool = False, fail_generate: bool = False)` implementing the port; attribute `calls: list[str]`; whitespace tokenizer (ids = positions); `generate` returns `output_tokens = min(max_new_tokens, 3)`.
- Use cases log with stdlib `logging.getLogger(__name__)` events `model_load_started|succeeded|failed`, `generation_completed` with only safe `extra` keys: `model_id`, `revision`, `prompt_tokens`, `output_tokens`, `error_type`.

### Task 4: Transformers adapter and contract tests

**Files:**
- Create: `backend/app/adapters/outbound/inference/transformers_adapter.py` (+ `__init__.py`s)
- Create: `backend/tests/contract/model_execution_contract.py` (shared base class), `backend/tests/contract/test_fake_contract.py`, `backend/tests/contract/test_transformers_contract.py`
- Test: `backend/tests/adapters/test_transformers_adapter_without_ml.py`

**Consumes:** `ModelExecutionPort`, `FakeModelExecution`.

**Produces:** `TransformersInferenceAdapter(device: str = "cpu")` implementing the port.
- `load`: import `torch`/`transformers` **inside** the method; on `ImportError` raise `ModelLoadError("ML dependencies not installed; run: uv sync --extra ml")`; use `AutoTokenizer`/`AutoModelForCausalLM.from_pretrained(spec.model_id, revision=spec.revision, trust_remote_code=False)`; wrap any other exception in `ModelLoadError` (message without secrets/paths); set eval mode; `is_loaded()` true only after full success.
- `tokenize`: raw prompt, no chat template (documented limitation); `generate`: greedy (`do_sample=False`), `max_new_tokens` from config, `torch.inference_mode()`, `output_tokens` = new tokens only, `prompt_tokens` = input ids length, decode with `skip_special_tokens=True`. A `threading.Lock` guards load/unload/generate. Runtime errors → `InferenceFailedError`.
- `unload`: drop references, `gc.collect()`, idempotent.

**Contract suite** (`ModelExecutionContract`, subclasses supply `make_port()` and a `valid_spec`): not-loaded errors for `tokenize`/`generate`; `is_loaded` False→True→False; `tokenize("hello world").count > 0`; unicode `"héllo 🌍"` tokenizes without error; `generate(...)` gives `1 <= output_tokens <= max_new_tokens` and `prompt_tokens == tokenize(prompt).count`; operations after `unload` raise `ModelNotLoadedError`; double `unload` is fine; load of `ModelSpec("invalid/does-not-exist", <pinned sha>)` raises `ModelLoadError` and `is_loaded()` stays False, then a valid load succeeds.
